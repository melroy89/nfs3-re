# Modern Patch change catalog

## Scope and evidence status

This is a traceability backlog transcribed from the installed English release notes, not a count of independently confirmed binary changes. It contains 290 release-note bullet entries across 12 dated versions. A bullet may bundle several changes, describe a regression or dependency, or cover documentation/configuration; one code change may also span several bullets. IDs are stable within this catalog (`MP` + version digits + release-local bullet number). Descriptions below are shortened release-note extracts, sometimes lightly edited; they retain vendor wording and are not independent code-level explanations. Every row defaults to vendor-claimed until a separate original-versus-Modern comparison is linked.

Readme: `nfs3_decomp.rep/Electronic Arts/Need For Speed III/readme_en.txt` (SHA-256 `02bf4684dce1073b4fe7c00c747f020b43508b0cf1407b5dc3f3b864ea46d81d`). The listed package release is Modern Patch v1.6.1 dated 2016-10-28. Official download page/archive: [Modern Patch download](https://veg.by/files/nfs3/nfs3_modern_patch.7z).

Several bounded findings now have dual-binary static evidence; see the [comparison overview](original-modern-differences.md) and row-specific links. The [x87 comparison](og-modern-x87-precision.md) and qualified renderer entries distinguish established parts; their release-introduction dates and runtime behavior remain unverified. RaceNet has a separate original-versus-active-build comparison in [connect menu dispatch crosswalk](connect-menu-dispatch-crosswalk.md); it is a specific menu-routing finding, not verification of the other multiplayer release notes.

Source line points to the bullet in the installed `readme_en.txt`. Release anchors: v1.0.0 2015-05-17; v1.1.0 2015-05-22; v1.2.0 2015-06-10; v1.3.0 2015-06-22; v1.3.1 2015-07-14; v1.4.0 2016-02-16; v1.5.0 2016-03-20; v1.5.1 2016-03-25; v1.5.2 2016-04-10; v1.5.3 2016-05-03; v1.6.0 2016-09-22; v1.6.1 2016-10-28. The README overview separately says “More than 200 changes at all”; this catalog’s 290 is a bullet-entry count, not a validation of that claim.

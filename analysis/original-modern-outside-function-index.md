Run the inventory generator in a separate checkout when reproducing the counts, since it also rewrites this Markdown file. [Complete machine-readable inventory](evidence/audits/outside-function-differences.json), [baseline comparison](original-modern-differences.md).

The **21,926 differing bytes** outside the saved Modern body union occupy **337 maximal uncovered intervals with changes**: **18,098** have Modern byte`90` (NOP), **605** have byte`00`, and **3,223** have other values. These are byte classes, not semantic explanations or completion percentages.

Intervals include unchanged bytes and can contain removed original code, old epilogues, embedded data or unrecognized Modern code. A NOP replacement is not automatically dead code or padding. Ranges are half-open. Full hashes and every contiguous changed run are retained in JSON.
